# Weather Forecast Application

## Introduction

The Weather Forecast Application is a web-based solution that allows users to check current weather conditions and receive forecasts for the upcoming days. The application utilizes the WeatherAPI service to provide accurate weather data, dynamically displayed through an intuitive user interface built with React, HTML, CSS, and JavaScript.

## Overall Structure

* Frontend (React): Provides a responsive and dynamic user interface to display weather forecasts.

* Material UI : Enhances the app’s visual appeal and responsiveness.

* JavaScript (API Integration): Handles data fetching and updates the UI dynamically.

## Steps to Development

Project Setup: Initialize the React app using Create React App.

Component Design: Develop reusable components for displaying weather information.

API Integration: Fetch weather data using WeatherAPI and process it for display.

UI Styling: Apply CSS styles to ensure a responsive layout.

Deployment: Deploy the application using platforms like Vercel.

## Architecture Overview

Frontend

Developed using React for a dynamic user experience.

The interface updates instantly as the user searches for a new city, utilizing React's state management.

Styled with CSS to ensure a clean, user-friendly experience across devices.

API Integration

The app fetches weather data via WeatherAPI, which provides accurate and up-to-date weather information.

Asynchronous requests are made using JavaScript's Fetch API, ensuring smooth user interactions.

Responsive Design

The app utilizes Material UI React library to ensure responsiveness across all device sizes, from mobile phones to desktop monitors.

## Requirements

* A modern web browser (Chrome, Firefox, Edge, etc.).

* Internet connection to fetch weather data from WeatherAPI.

* Node.js and npm installed for package management.

## Steps

* Clone Repository: Download the project files from the GitHub repository : https://github.com/Cathyy1212/Webstack-Portfolio-Project.git

* Install Dependencies: Run npm install to install necessary packages.

* Run Application: Execute npm start to launch the app in development mode.

* Access the App: Open http://localhost:3000 in your browser.
